Run & Test Instructions

Install & browsers: bash setup.sh.
Because Windows currently reserves TCP ports 2973‑3072 (netsh int ipv4 show excludedportrange protocol=tcp), binding to 3000 fails without elevation. Until that reservation is removed, export a safe port (e.g. PowerShell $env:PORT=4173; npm start or npm run start:ci) and visit http://127.0.0.1:4173. Once port 3000 is freed, simply run npm start to serve on 3000 as coded.
Automated tests: bash run_tests.sh (or npm test).
Screenshot regeneration: npm run screenshot (drops a fresh artifacts/dashboard.png).
Manual review: open public/buggy.html for the defect reproduction, and http://127.0.0.1:<port> for the fixed UI.
Let me know if you need the port-3000 reservation cleared differently or if you’d like additional Playwright coverage.
